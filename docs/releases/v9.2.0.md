# NOOP v9.2.0

An accuracy-and-breadth release on top of 9.1.0. The headline is an **HRV correction** that affects
every user's numbers, a large step forward for **Oura** (nights that score, the ring's own hypnogram,
motion), considerably more of the **WHOOP 5/MG** record decoded and banked, and a **sync you can
stop**. Everything still runs on your own device, offline, no account.

**One thing to know before updating:** the HRV fix changes your numbers. Same-second R-R intervals
were being read in magnitude order rather than the order the strap emitted them, which biased RMSSD
downward — measurably so. Post-update HRV is the correct value, but it will not match yesterday's.

## New

- **Oura nights that actually score (#774, #728).** Banked overnight IBI is now derived into
  `hrSample`, so the nightly pipeline has something to score. Previously an Oura night stored real
  beats and still came back NULL.
- **The Oura ring's own sleep staging (#773).** The SleepNet hypnogram is persisted as a stage
  timeline labelled "Oura", beside NOOP's own staging rather than replacing it.
- **Oura motion (#805, #834).** `0x47` motion events decode to an averaged acceleration vector shaped
  like WHOOP 4.0 gravity, persisted as `OURA_MOTION` and surfaced as a Movement track.
- **Stable Oura identity (#771, #772, #776).** The ring is identified by its serial and its generation
  read from the hardware id, so re-pairing no longer orphans all its history, and the generation is
  no longer mis-read from stray digits in the BLE name.
- **v18 per-second fields are banked (#848).** Seventeen channels the 5/MG decoder already produced
  and the storage funnel then discarded are now persisted per second, with absence as a first-class
  state rather than a silent zero. Instrumentation for now — nothing reads them yet — but the strap
  trims its history the moment a sync is acked, so an unbanked field is unrecoverable.
- **Feature-flag enumeration probe (#761).** A read-only, default-off diagnostic that asks a strap to
  list the feature-flag names its own firmware knows. Writes no value; the SET commands are never
  sent from it. Aimed at #103 — a strap that names no oxygen flag is itself an answer.
- **Detailed sleep stages to Health Connect (#744).** Android now exports stage-level sleep, not just
  the session.
- **Sync-status chip on Today (#245, #806).** Tells you whether the strap is syncing, caught up, or
  has never handed anything over.
- **Confirm before ending an active workout (#523).**

## Fixed

- **HRV read low because R-R beats were sorted by magnitude (#823, #830).** Same-second intervals were
  ordered by value rather than emission order. RMSSD is a successive-difference measure, so reordering
  changed the answer. Fixed, along with four downstream sorts that would have undone it.
- **Workout HR disagreed with itself across surfaces (#856, #857).** The chart, zone minutes and Avg HR
  each resolved the recording strap differently. One rule now: a detected bout reads the strap that
  recorded it; a manual or imported one reconciles against the worn strap.
- **Escalating battery alerts (#864).** The 15% and 24-hour alerts both latch until a charge, so a
  strap that kept draining went silent exactly as it got worse. A 12% critical crossing and a bedtime
  night-guard now have their own gates.
- **`GET_DATA_RANGE` field offsets (#818).** `pagesBehind` was read from the wrong offsets.
- **v18 `@36` and `@106`/`@107` were mis-typed (#861).** `@36` is a flag byte, not a higher-precision
  heart rate — the correlation that suggested otherwise was circular. `@106`/`@107` are two
  independent u8 channels, not one u16.
- **Health Connect calories were under-reported and double-counted (#835, #842).**
- **The sync chip crashed its own unit tests (#859).** A "pure" state decision reached for the
  Application's resources and the system clock.
- **Today score source badges (#778).**
- **iOS tab-swipe broke NavigationStack's back-swipe (#519).**
- **Dynamic Island rendering in unsigned iOS builds (#742).**

## Under the hood

- **Stop a running sync (#875).** `ABORT_HISTORICAL_TRANSMITS` is wired on both platforms. Nothing is
  lost: the strap only frees records once NOOP acks them, so an aborted drain re-offloads intact.
- **SpO₂ candidate validation is a lot less credulous (#860, #868).** The `@82` byte is duty-cycled —
  a 30-second window every 20 minutes — so a capture that misses the phase reads all zeros and looks
  exactly like a strap with the feature off. The harness now measures the schedule per capture,
  aggregates per window, screens candidate bytes for real variance, and refuses to claim "feature
  absent" from a capture that could not have seen a window.
- **Two CI gates added.** A doc-comment linter that catches comments documenting nothing (#849), and
  i18n coverage extended to the four locales it had never checked (#844, #850).
- **pt-PT is complete (#768, #769)**, and the battery-alert strings now exist in all eight Apple
  languages and all six Android locales (#866).
- **Android dependency verification works off-Linux (#854).**
