# NOOP v10.1.0

A release about giving you your own numbers — heart-rate zones you set, two straps you can compare and
switch between — and about the numbers you already have being more honest: HRV that admits when a night
is unreliable, sleep debt measured against your own need, and cleaner Oura nights. It builds on 10.0.0.
Everything still runs on your own device, offline, with no account.

## Scores that change

Read this first — a few changes alter values you have already seen.

- **HRV on an over-counted WHOOP 4.0 night is now flagged (#1118).** When a night's R-R stream is
  over-counted, the HRV number is captioned **unverified** rather than shown as fact. The value is not
  changed yet — the fix for the count itself is still landing — but you will now see which nights to
  distrust.
- **Sleep debt is measured against your personalized need (#1348),** not a fixed target, so your debt
  figure reflects how much sleep *you* actually need.
- **Rest and readiness gain a previously-disconnected methodology (#456, #1335).** Scoring logic that
  had been built but never wired in is now part of Rest and readiness, which moves those scores.
- **Duplicate and phantom Oura sleep nights are collapsed (#1284, #1338).** A pre-onset fragment or a
  re-banked copy that used to show as a second, wrong night is now folded into the real one — so an
  affected Oura night reads once, at the right window.
- **Nightly SDNN is now stored alongside RMSSD (#1334).** A broader autonomic-variability figure (the
  5-minute SDNN index) is kept beside the usual HRV; a mislabelled HealthKit SDNN export is corrected.

## New

- **Personalized heart-rate zones (#531).** Set custom BPM thresholds in a Settings editor; the whole
  app — every zone read-out, and your `.noopbak` backup — routes through your effective zone set.
- **Compare two straps, and switch the active one (#1300).** A two-strap comparison engine and a
  Compare-Straps card correlate two devices you own; a strap switcher flips which one is active. The
  data is correlated, never combined.
- **More of the Oura ring decoded, as instrumentation (thanks @pipiche38).** The ring's own **breath
  rate** (0x6A, #1384) and **step features** (0x7E/0x7F, #1359) are decoded and shown beside your other
  numbers — read off the ring, never fed into a score. The 0x6B motion decode is corrected to the
  documented layout (#1357).
- **Polish localization (#1250).**
- **A truthful empty state for the experimental Rhythm view (#1360)** — an honest "no data" when a
  device can't support the reading, rather than a blank or a guess.
- **Unlock VO₂max, with tappable fixes (#1333).** The Fitness card surfaces what's missing and how to
  provide it.
- **Five more WHOOP-catalogue sports (#1327), and per-sport workout icons on Android (#1329)** to match
  iOS.
- **Hide cycle awareness entirely (#1380)** — a private, user-controlled choice, never based on age.
- **Save custom journal behaviours to your backup (#1361),** and a clinician-share export builder for
  Rhythm (#1298).
- **See background syncing in the Today battery indicator (#837).**

## Fixed

- **Sleep no longer truncates today's read at 18:00 (#1370),** and sleep edit/delete now resolves the
  owner across every namespace it can appear under (#1325).
- **Multi-strap correctness (#1304, #512).** WHOOP badge day/workout/HR counts now sum across every
  strap you own, and the live paths read the *active* strap instead of a hardcoded id.
- **A paired device's name is no longer hardcoded to "WHOOP 4.0" (#1355, thanks @pipiche38).**
- **Respiratory rate is labelled as the on-device estimate it is on both WHOOP generations (#1367)** —
  it was never read off the strap.
- **Today's carried-over vitals stop reading as a fresh measurement (#1312, #1331),** honouring °C/°F on
  skin temperature and bounding the carry.
- **A declined file picker no longer wedges the Backup screen (#1324);** the Deep-Timeline chart no
  longer hijacks a touch scrub with a pan (#1343); the manual-workout sheet scrolls instead of shifting
  (#1336).
- **German strap-gender wording in Android onboarding (#1358, thanks @ben-tsk).**
- **A Stress Index reading is refused from a mostly-rejected spot capture (#1340),** and the phone
  HR-broadcast warning on the Data Sources card is corrected and clarified (#159).
- **A batch of i18n fixes,** including catching translations that were still the English source (#1369).

## Under the hood

Diagnostics and instrumentation that don't change what you see, but make the next fixes possible: an
Oura cross-connection duplicate-generation diagnostic and its follow-ups (#1339, #1353, #1354, thanks
@pipiche38), a shadow-logged deduped R-R stream to validate the HRV over-count fix (#1352), a WHOOP-4.0
serial-locating dump (#1303), and a set of offline WHOOP reverse-engineering tools (#1306). Plus
assorted performance work on the analyze pass and the Explore screen (#1346, #1368).
